## Запустить

Требуется Node.js 22 или новее (проверено на 24.21.0).

```bash
npm ci
npm start
```

Откройте http://localhost:3000. Переменная PORT задаёт порт; по умолчанию 3000. Сборки и базы данных нет. Один Node.js процесс обслуживает HTML, CSS, Canvas и WebSocket.

Для игры в локальной сети друзья открывают http://IP-КОМПЬЮТЕРА:3000. Для игры через интернет сначала опубликуйте сервер. Открытие index.html напрямую и статические хостинги без WebSocket-сервера для этой версии не подходят.

## Публикация на Netlify

Игра подготовлена для Netlify Server в регионе Frankfurt (fra). Подключите этот GitHub-репозиторий к проекту Netlify и выберите рабочую ветку. Node.js 24 задаётся файлом .node-version; каталог сайта — public. Файл netlify.toml задаёт один сервер и регион. Netlify Server находится в раннем доступе; проверьте доступность и тариф в своём аккаунте перед публикацией.

Сервер хранит комнаты в памяти. После перезапуска они удаляются. В раннем доступе Netlify закрывает WebSocket-соединения по истечении лимита длительности запроса (на Free до 30 минут); повторное соединение не восстанавливает матч. Сервер засыпает после 5 минут без запросов и открытых соединений. Текущее ценообразование и ограничения: [Netlify Server](https://docs.netlify.com/build/server/), [ограничения](https://docs.netlify.com/build/server/limits/), [регионы](https://docs.netlify.com/build/server/configuration/#region).

## Бесплатная публикация на Render

В репозитории есть render.yaml. Добавьте исходники в GitHub, затем в панели Render создайте Blueprint из этого репозитория. Проверьте, что выбран тариф Free. Альтернатива: создайте Web Service с runtime Node, Build Command: npm ci --omit=dev, Start Command: npm start и Health Check Path: /health. Секретов и API-ключей игра не требует.

После публикации откройте выданный HTTPS-адрес, создайте комнату и отправьте друзьям адрес сайта вместе с шестизначным кодом. Все должны использовать один адрес сервера.

У бесплатного веб-сервиса есть ограничения: возможен медленный первый запуск после простоя; при перезапуске комнаты и матчи теряются. Держите одну инстанцию: комнаты хранятся в памяти процесса. Не перезагружайте страницу во время матча: восстановление сессии не реализовано, потребуется новая игра. Выход игрока передаёт капитанство следующему человеку; незавершённые задания ушедшего мирного засчитываются, чтобы не блокировать победу.

Актуальные условия платформы: [бесплатные сервисы](https://render.com/docs/free), [WebSocket](https://render.com/docs/websocket), [Blueprint](https://render.com/docs/infrastructure-as-code). Развёртывание в аккаунте пользователя не выполнялось.

## Как играть

- 4–15 участников. Можно добавить ботов в лобби. Капитан задаёт число предателей, скорость и время голосования. Фактическое число предателей ограничено floor((игроки−1)/3), максимум 3.
- Цвет и позывной меняются в лобби. Всего 15 цветов.
- Тренировка создаёт закрытый экипаж с 7 ботами и позволяет выбрать любую роль.
- WASD / стрелки: движение и направление взгляда. Физические клавиши работают и при русской раскладке. E: задание; R: сообщить о теле; M: карта. На телефоне есть стрелки.

- Жёлтые терминалы: задания. Люки: слева внизу отсеков. На центральном посту расположены кнопка собрания и отдельный терминал саботажа для предателей. Кнопки можно нажать на карте, подойдя к ним.

<!-- /coderabbit-ai-generated:v1 -->
- Чат есть в лобби, в полёте и на собрании; сообщения призраков скрыты от живых. Встроенного голосового чата нет.
- Мирные побеждают при 100% общих заданий или отсутствии живых предателей. Призраки могут выполнять задания.
- Предатели побеждают, если остаётся не более одного мирного либо истекают 45 секунд аварии реактора.

## Роли

| Роль | Способности |
| --- | --- |
| Мирный | Только задания и голосование. |
| Киррил | Борщ ближайшему мирному раз в 40 сек. Получатель включает борщевую тягу на 10 сек. |
| Никита | Стена из блоков перед собой раз в 30 сек. Исчезает через 18 сек. |
| Саня Гиперфарм | Орёл/решка раз в 15 сек. Верная ставка +10% общего прогресса, третья ошибка за матч убивает. |
| Илья | Невидимая зеркальная броня на 10 сек, перезарядка 40 сек. Отражает направленную атаку. |
| Егор | Лужа раз в 20 сек на 18 сек. В ней ускорение и мгновенные задания. |
| Предатель | Убийство раз в 20 сек, вентиляция и саботаж: свет / реактор / двери. Эти действия доступны всем предателям. |
| Саня | Телепорт в выбранный отсек раз в 40 сек, скрытый выстрел по коленям раз в 30 сек: задания жертвы уменьшают прогресс. |
| Артём | Красота на 3 сек раз в 60 сек. Убивает мирных в радиусе 350, смотрящих на него (направление задаёт движение). |
| Крокс | Ток раз в 60 сек поражает до 2 мирных цепочкой. Кирка раз в 60 сек у стены засасывает до 3 мирных в радиусе 240 без визуального эффекта разрушения. |
| Фортис | Самоподрыв: до 5 мирных в радиусе 300 и сам Фортис. Бомба на ближайшего мирного раз в 30 сек; детонация убивает носителя и ещё одного мирного в радиусе 130. |
| Дима | Управляемая WASD ракета раз в 60 сек (до 12 сек); персонаж скрыт до её завершения. Стена гасит ракету, мирный погибает от попадания. Лазер раз в 30 сек даёт белый экран на 4 сек мирным в радиусе 300. |

Неуказанные в запросе значения длительности/радиуса выбраны для играбельности. Борщевая тяга и лужи увеличивают скорость в 1.85 раза. Направленные действия выбирают ближайшую доступную цель; союзные предатели не поражаются. Роли могут повторяться. Боты ходят, делают задания, убивают и сообщают о телах; в голосовании пропускают, особые способности не используют. Это упрощённые соперники для тренировки.

## Проверки

```bash
npm run check
npm test
```

Тесты проверяют роли, секретность брони и повреждения коленей, задания, таймеры, голосование, границы карты, ракеты, взрывы, победу и настоящий обмен WebSocket между клиентами. Сервер рассчитывает движение, атаки и условия победы. Мини-игры заданий проверяют последовательность и минимальную длительность; это не защита от всех видов читов. Матчи в памяти, без сохранения и восстановления после обрыва связи.
